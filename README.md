# A-stochastic-policy-assessment-of-Spain-s-81-renewable-electricity-target-for-2030
Open-source Julia/JuMP probabilistic dispatch model of the Iberian electricity market (MIBEL) to assess Spain's 81% renewable target for 2030. Uses a 10,000-iteration Monte Carlo framework to evaluate compliance, emissions, and prices under capacity, fuel, demand, and climate uncertainties.
